# عقارات

مستودع خاص لعقارات العيلة (شقة، فيلا، شاليه). كل عقار ليه **ملف بيانات واحد** فيه الأبعاد والحيطان والفتحات والأثاث وأماكنه، والعارض 3D بيقرأ منه.

## الشكل
```
apartments/apt1/model.json   # الشقة الأولى (الأبعاد + الأثاث)
apartments/apt1/NOTES.md     # اللي نعرفه واللي لسه محتاج قياسه
viewer/index.html            # عارض 3D (مشي، منظور علوي، تعديل العفش)
tools/build_single.py        # يبني ملف HTML واحد فيه البيانات (للنشر كـ artifact)
```
عقار جديد: مجلد جديد جنب `apt1` (مثلًا `villa1`) بنفس شكل `model.json`، وبيتفتح بـ `viewer/index.html?apt=villa1`.

## التشغيل محليًا
```bash
python3 -m http.server 8000
# افتح http://localhost:8000/viewer/index.html
```

## تعديل العفش
من العارض نفسه: تبويب «العفش» → اضغط على القطعة → حرّكها بالأسهم أو لفّها. التعديلات بتتحفظ على الجهاز، وبتتشارك برابط (`#e=…`)، وبتتثبّت في `model.json` لما نطلبها من Claude.

## الخصوصية
المستودع خاص لأن فيه مخططات الأملاك. ما تخليهوش عام.
